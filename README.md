
# GameHub

GameHub is a simple video game website created for Assignment #2 in Web Technologies.

## Features

- Navigation bar built with Flexbox
- Game cards with images, descriptions and buttons
- Page layout built with CSS Grid
- Image gallery with nine game images
- Responsive design for smaller screens
- Portfolio page with featured games

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid

## Project Structure

- index.html - Home and portfolio page
- cards.html - Game cards
- grid.html - Grid layout
- gallery.html - Game gallery
- style.css - Website styles
- images - Game images

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open index.html in a browser.
